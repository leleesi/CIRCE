# CIRCE 0.0.1

[@leleesi](https://github.com/leleesi) · [leleesi/CIRCE](https://github.com/leleesi/CIRCE)

## Português

Primeira versão pública de código aberto para **Windows 11 x64**. O CIRCE mede duas passagens pela mesma cena e mostra o efeito das alterações nas definições do jogo.

- Abre o painel com **Ctrl + Home**, escolhe o jogo e regista **Antes** e **Depois** durante 15, 30 ou 60 segundos.
- Compara FPS médios, P99 do tempo de fotograma e variação percentual. Guarda o PDF ou o vídeo lado a lado na pasta que escolheres.
- Escolhe português ou inglês no instalador. O componente de vídeo é opcional e requer Internet na instalação. Todas as funções são gratuitas.

## English

First open-source release for **Windows 11 x64**. Run the same scene twice to see how a settings change affects performance.

- Press **Ctrl + Home**, select the game and record **Before** and **After** runs of 15, 30 or 60 seconds.
- Compare average FPS, P99 frame time and percentage change. Save a PDF or a side-by-side video to a folder of your choice.
- Select English or Portuguese in the installer. The optional video component needs Internet during installation. Every feature is free.
